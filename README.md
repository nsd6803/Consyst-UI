# Consyst UI

Дизайн-система платформы «ПроДвижение» и её документация. Подход к коду — как в shadcn/ui: компонент копируется в проект и дальше принадлежит команде. Токены устроены по слоям, как в Ant Design. Поведение и доступность сложных компонентов — на Radix.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run tokens   # пересобрать цвета из JSON и проверить контраст (WCAG AA)
npm run build    # статическая сборка в dist/
```

Иконки — векторные SVG из Font Awesome Free Solid ([CC BY 4.0](https://fontawesome.com/license/free)), шрифт для них не нужен. Пути в `src/registry/icons.tsx` генерирует `npm run icons`.

## Структура

```
src/
├─ tokens/
│  ├─ primitives.json   — слой 1: палитры (neutral, blue, green, amber, red, violet)
│  ├─ semantic.json     — слой 2: смысловые цвета для light/dark + пары для проверки контраста
│  └─ contrast.json     — отчёт по контрасту (генерируется)
├─ styles/consyst.css   — все токены: типографика, отступы, размеры контролов, радиусы, тени,
│                          движение + сгенерированные цвета и классы типографики
├─ registry/            — компоненты (*.tsx + *.css), которые копируют разработчики
├─ examples/            — примеры; их код показывается во вкладке «Код»
└─ docs/                — сайт документации; config.ts — список компонентов, API, рекомендации
scripts/build-tokens.mjs — генератор цветов + проверка контраста
```

## Правила

- Компоненты используют только семантические токены (`--color-*`, `--space-*`, `--control-height-*`), никаких hex-значений.
- Размеры контролов общие: sm 32 / md 40 / lg 48.
- Новые цвета добавляются в `semantic.json`, затем `npm run tokens`. Если контраст не проходит, скрипт падает.
- Файлы и npm-зависимости компонента документация вычисляет сама по импортам.
