# Consyst UI

Документация дизайн-системы проекта «ПроДвижение» в стиле shadcn/ui: превью компонента, код на React и кнопка «Копировать».

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статическая сборка в dist/ — можно выложить на любой хостинг
```

## Структура

```
src/
├─ styles/consyst.css   — токены из Figma (цвета, типографика, отступы, радиусы, тени) + @font-face Rosatom
├─ registry/            — исходники компонентов (то, что копируют разработчики): *.tsx + *.css
├─ examples/            — примеры; их код показывается во вкладке «Код»
└─ docs/                — сам сайт документации
   └─ config.ts         — список компонентов, описания, API-таблицы, ссылки на Figma
public/fonts/           — шрифт Rosatom
```

## Как добавить компонент

1. Положите `name.tsx` и `name.css` в `src/registry/`.
2. Создайте пример `src/examples/name-demo.tsx` (импорт из `@/components/ui/name`).
3. Добавьте запись в `components` и в `nav` в `src/docs/config.ts`.

Код на странице берётся напрямую из файлов (`?raw`), поэтому документация всегда совпадает с реальным кодом.
